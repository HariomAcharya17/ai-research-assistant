# AI Research Assistant

A web app where users enter a research idea or upload a draft paper. An AI agent searches for closely related research papers, explains what each paper covers, and helps the user develop their own work with accurate references.

## Main features

- **Search academic sources.** Find papers from Springer, IEEE Xplore, Google Scholar and Scopus-indexed journals. Show title, authors, year, abstract, source, DOI and a link to the publisher or paper page.
- **Rank related papers.** Order results by how closely they match the user's idea and explain the match. Presented as a relevance ranking, not a fixed similarity percentage unless that score has been tested and defined.
- **Read and explain papers.** Summarize accessible papers: research question, methods, findings and limitations. Link each summary to the passages or sections it came from.
- **Identify possible research gaps.** Compare papers and suggest follow-up questions, keeping author-stated limitations separate from AI-generated suggestions.
- **Help with citations.** Generate citations and reference lists in the user's chosen style, based on verified source details.
- **Check uploaded drafts.** Flag text that matches sources the app can access and show the possible matches. This is a similarity check, not a guarantee that the work is plagiarism-free.
- **Improve writing responsibly.** Help with grammar, clarity, structure and properly cited paraphrasing. Rewriting is not designed to disguise copied text or evade plagiarism detection.

## Sources and access

Papers are labelled by source and, where possible, journal indexing is verified using reliable metadata. Full-text access depends on open-access availability, publisher access, or a PDF provided by the user.
